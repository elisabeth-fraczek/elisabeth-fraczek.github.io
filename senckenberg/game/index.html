How to play

  1. Give one answer per round. Common alternative names count.
  2. Among the answers on the game’s list, articles with fewer views earn more points.
  3. Explore the full answer list after the last round.

Scoring data

Wikimedia Analytics

The game accepts different spellings in three ways:

  1. Aliases ChatGPT hardcoded. In game/data/questions.json, Common buzzard, Mäusebussard, and Buteo buteo all map to the same answer and earn the same points.
  2. Automatic text cleanup. The game ignores capitalisation and accents, and treats hyphens as spaces. So SENTINEL-2 and sentinel 2 match the same answer.
  3. Wikipedia redirects. When the data is refreshed, the script follows redirects for the article titles in the question file. For example, Wikipedia redirects Habitat restoration to Ecological restoration, so the game accepts both titles.

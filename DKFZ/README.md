# DKFZ-Bewerbungswebsite

## Auf GitHub Pages veröffentlichen

1. Den Ordner dkfz in dein Repository elisabeth-fraczek.github.io kopieren.
2. Die Dateien mit Git committen und pushen.
3. Nach der Veröffentlichung durch GitHub Pages ist die Website unter
   https://elisabeth-fraczek.github.io/dkfz/ erreichbar.

## Inhalte bearbeiten

- dkfz/index.html enthält die Startseite.
- dkfz/about/index.html enthält die Fotogalerie und Bildunterschriften.
- dkfz/assets/site.css enthält Farben, Schriften und die mobile Darstellung.
- dkfz/assets/gallery.js öffnet die vergrößerten Fotos.
- dkfz/assets/photos enthält deine Fotos.
- dkfz/documents/Elisabeth_Fraczek_Lebenslauf.pdf ist der verknüpfte Lebenslauf.

## Lokal ansehen

Im entpackten Ordner neben dkfz einen lokalen Webserver starten.

    python3 -m http.server 8000

Dann http://localhost:8000/dkfz/ im Browser öffnen.

Die Schriftarten und Fotos sind im Paket enthalten.
